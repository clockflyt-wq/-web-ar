طريقة تشغيل الموقع للناس كلها (مع ذكاء اصطناعي حقيقي)

1) مفتاح الذكاء الاصطناعي
   - ادخل console.anthropic.com واعمل حساب، واعمل API Key جديد.
   - حط حد أقصى للصرف الشهري من إعدادات الحساب (مهم عشان ما تتفاجئش بفاتورة).

2) رفع الموقع (مجاني على Vercel)
   - اعمل حساب على github.com وارفع محتويات الفولدر ده في Repository جديد
     (index.html و package.json وفولدر api).
   - ادخل vercel.com بحساب GitHub، واضغط Add New > Project واختار الـ Repository.
   - قبل ما تضغط Deploy: افتح Environment Variables وضيف
       الاسم: ANTHROPIC_API_KEY
       القيمة: المفتاح اللي عملته
   - اضغط Deploy. هتاخد رابط https جاهز تبعته للناس.

3) الاستخدام
   - افتح الرابط في كروم، واضغط "اعرض التارجت" وافتحه على شاشة تانية أو اطبعه.
   - اضغط "شغّل الكاميرا" ووجّهها على التارجت.
   - الميكروفون بيشتغل على كروم. في المتصفحات التانية استخدم خانة الكتابة.

ملاحظات
   - كل رد من الذكاء الاصطناعي بيتحسب عليك. لو الموقع انتشر حط حدود صرف أو زوّد حماية ضد الإساءة.
   - لو السيرفر وقع أو وصل للحد الأقصى، الروبوت بيرد بردود جاهزة بدل ما يسكت.
